# Native observability adapter

The shared `createAgentDoor` owns transport, policy, consent and review state.
This directory owns the two supported private read tools, native people mapping
and local credential admission. Read tools call the same query and definition
readers as REST and the UI; a trusted server principal never becomes a cookie,
HTTP argument or manufactured native session.

See `docs/company-agents.md` for supported jobs and limits, and `agent-surface.json` for
the core-only declaration and public-door journey. New native agent actions need
native authorization, classification, summaries, attribution and journey evidence
before they may enter this registry.
